# ThemeMidnightPlugin

Midnight theme plugin for Cisum, providing a deep dark midnight-inspired color scheme.

## Overview

This plugin registers with ID `ThemeMidnightPlugin` and provides the Midnight theme through the Cisum plugin system.

## Architecture

ThemeMidnightPlugin/
├── Package.swift
├── Sources/ThemeMidnightPlugin/
