# BookProgressPlugin

Book playback progress tracking plugin for Cisum, providing progress display and state management for audiobooks.

## Overview

This plugin registers with ID `BookProgressPlugin` and provides playback progress tracking through the Cisum plugin system.

## Architecture

```
BookProgressPlugin/
├── Package.swift
├── Sources/BookProgressPlugin/
│   ├── BookProgressPlugin.swift

└── Tests/
```
