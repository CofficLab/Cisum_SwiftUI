# AudioDownloadPlugin

Audio download management plugin for Cisum, handling audio file downloads with progress tracking.

## Overview

This plugin registers with ID `AudioDownloadPlugin` and provides audio download functionality through the Cisum plugin system.

## Architecture

```
AudioDownloadPlugin/
├── Package.swift
├── Sources/AudioDownloadPlugin/
│   ├── AudioDownloadPlugin.swift
│   ├── AudioDownloadPluginInfo.swift
│   └── AudioDownloadRootView.swift
└── Tests/
```
