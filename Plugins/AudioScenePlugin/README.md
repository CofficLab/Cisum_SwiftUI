# AudioScenePlugin

Audio scene and poster plugin for Cisum, providing visual scene/poster artwork for audio content.

## Overview

This plugin registers with ID `AudioScenePlugin` and provides audio scene/poster functionality through the Cisum plugin system.

```

├── Sources/AudioScenePlugin/
```
