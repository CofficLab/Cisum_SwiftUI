# BookSettingsPlugin

Book settings management plugin for Cisum, providing configuration options for audiobook playback behavior.

## Overview

This plugin registers with ID `BookSettingsPlugin` and provides book settings functionality through the Cisum plugin system.

## Architecture

```
BookSettingsPlugin/
├── Package.swift
├── Sources/BookSettingsPlugin/
│   ├── BookSettingsPlugin.swift
│   ├── BookSettingsPluginInfo.swift
│   └── BookSettingsView.swift
└── Tests/
```
