# WelcomePlugin

Welcome and onboarding plugin for Cisum, providing first-launch experience with storage selection.

## Overview

This plugin registers with ID `WelcomePlugin` and provides onboarding functionality through the Cisum plugin system.

## Architecture

```
WelcomePlugin/
├── Package.swift
├── Sources/WelcomePlugin/
│   ├── WelcomePlugin.swift
│   ├── WelcomePluginHost.swift
│   ├── WelcomePluginInfo.swift
│   ├── WelcomeView.swift
│   ├── WelcomeStorageSelection.swift
│   └── StorageView.swift
└── Tests/
```

## Features

- **Welcome Screen**: First-launch welcome experience
- **Storage Selection**: Choose initial storage location
- **Onboarding Flow**: Guided setup for new users
