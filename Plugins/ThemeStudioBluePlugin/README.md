# ThemeStudioBluePlugin

Studio Blue theme plugin for Cisum, providing a professional blue studio-inspired color scheme.

## Overview

This plugin registers with ID `ThemeStudioBluePlugin` and provides the Studio Blue theme through the Cisum plugin system.
