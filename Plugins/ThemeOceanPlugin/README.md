# ThemeOceanPlugin

Ocean theme plugin for Cisum, providing a deep blue ocean-inspired color scheme.

## Overview

This plugin registers with ID `ThemeOceanPlugin` and provides the Ocean theme through the Cisum plugin system.

## Architecture

```
ThemeOceanPlugin/
├── Package.swift
├── Sources/ThemeOceanPlugin/
│   ├── ThemeOceanPlugin.swift
│   └── OceanTheme.swift
└── Tests/
```
