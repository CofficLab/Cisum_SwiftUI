# ThemeNebulaPlugin

Nebula theme plugin for Cisum, providing a cosmic nebula-inspired color scheme.

## Overview

This plugin registers with ID `ThemeNebulaPlugin` and provides the Nebula theme through the Cisum plugin system.

## Architecture

```
ThemeNebulaPlugin/
├── Package.swift
├── Sources/ThemeNebulaPlugin/
│   ├── ThemeNebulaPlugin.swift
│   └── NebulaTheme.swift
└── Tests/
```
