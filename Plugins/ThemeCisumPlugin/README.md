# ThemeCisumPlugin

Cisum default theme plugin, providing the brand's signature color scheme.

## Overview

This plugin registers with ID `ThemeCisumPlugin` and provides the default Cisum theme through the Cisum plugin system.

## Architecture

```
ThemeCisumPlugin/
├── Package.swift
├── Sources/ThemeCisumPlugin/
│   ├── ThemeCisumPlugin.swift
│   └── CisumTheme.swift
└── Tests/
```
