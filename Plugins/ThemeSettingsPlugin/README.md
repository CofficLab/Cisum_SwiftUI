# ThemeSettingsPlugin

Theme settings plugin for Cisum, providing the theme selection and configuration interface.

## Overview

This plugin registers with ID `ThemeSettingsPlugin` and provides theme management functionality through the Cisum plugin system.

## Architecture

```
ThemeSettingsPlugin/
├── Package.swift
├── Sources/ThemeSettingsPlugin/
│   ├── ThemeSettingsPlugin.swift
│   ├── ThemeSettingsPluginInfo.swift
│   └── ThemeSettingsRootView.swift
└── Tests/
```

## Features

- **Theme Selection**: Browse and select from available themes
- **Theme Preview**: Preview themes before applying
- **Theme Management**: Enable, disable, and configure themes
