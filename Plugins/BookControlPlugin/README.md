# BookControlPlugin

Book playback control plugin for Cisum, providing play, pause, skip, and speed controls for audiobooks.

## Overview

This plugin registers with ID `BookControlPlugin` and provides audiobook playback control functionality through the Cisum plugin system.

## Architecture

```
BookControlPlugin/
├── Package.swift
├── Sources/BookControlPlugin/
```
