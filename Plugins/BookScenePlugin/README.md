# BookScenePlugin

Book scene and poster plugin for Cisum, providing visual scene/poster artwork for audiobook content.

## Overview

This plugin registers with ID `BookScenePlugin` and provides book scene/poster functionality through the Cisum plugin system.

## Architecture

```
BookScenePlugin/
├── Package.swift
├── Sources/BookScenePlugin/
│   ├── BookScenePlugin.swift
│   ├── BookScenePluginInfo.swift
│   └── BookPosterView.swift
└── Tests/
```
