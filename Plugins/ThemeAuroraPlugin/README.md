# ThemeAuroraPlugin

Aurora theme plugin for Cisum, providing a colorful aurora-inspired color scheme.

## Overview

This plugin registers with ID `ThemeAuroraPlugin` and provides the Aurora theme through the Cisum plugin system.

## Architecture

```
ThemeAuroraPlugin/
├── Package.swift
├── Sources/ThemeAuroraPlugin/
│   ├── ThemeAuroraPlugin.swift
│   └── AuroraTheme.swift
└── Tests/
```
