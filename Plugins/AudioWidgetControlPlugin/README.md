# AudioWidgetControlPlugin

Audio widget control plugin for Cisum, enabling playback controls from home screen and lock screen widgets.

## Overview

This plugin registers with ID `AudioWidgetControlPlugin` and provides widget-based audio control functionality through the Cisum plugin system.
