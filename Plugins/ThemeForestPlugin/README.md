# ThemeForestPlugin

Forest theme plugin for Cisum, providing a nature-inspired green color scheme.

## Overview

This plugin registers with ID `ThemeForestPlugin` and provides the Forest theme through the Cisum plugin system.

## Architecture

```
ThemeForestPlugin/
├── Package.swift
├── Sources/ThemeForestPlugin/
│   ├── ThemeForestPlugin.swift
│   └── ForestTheme.swift
└── Tests/
```
