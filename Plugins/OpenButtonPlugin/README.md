# OpenButtonPlugin

Open current item button plugin for Cisum, providing a quick-access button to open the currently playing media.

## Overview

This plugin registers with ID `OpenButtonPlugin` and provides open button functionality through the Cisum plugin system.

## Architecture

```
OpenButtonPlugin/
├── Package.swift
├── Sources/OpenButtonPlugin/
│   ├── OpenButtonPlugin.swift
│   ├── OpenButtonPluginInfo.swift
│   └── OpenCurrentButtonView.swift
└── Tests/
```
