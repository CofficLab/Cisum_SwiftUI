# ThemePaperPlugin

Paper theme plugin for Cisum, providing a warm paper-inspired light color scheme.

## Overview

This plugin registers with ID `ThemePaperPlugin` and provides the Paper theme through the Cisum plugin system.

## Architecture

```
ThemePaperPlugin/
├── Package.swift
├── Sources/ThemePaperPlugin/
│   ├── ThemePaperPlugin.swift
│   └── PaperTheme.swift
└── Tests/
```
