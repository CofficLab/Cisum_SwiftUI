# AudioSettingsPlugin

Audio settings management plugin for Cisum, providing configuration options for audio playback behavior.

## Overview

This plugin registers with ID `AudioSettingsPlugin` and provides audio settings functionality through the Cisum plugin system.

```

├── Sources/AudioSettingsPlugin/
```
