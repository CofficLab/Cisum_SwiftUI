# ThemeGraphiteBlackPlugin

Graphite Black theme plugin for Cisum, providing a dark graphite-inspired color scheme.

## Overview

This plugin registers with ID `ThemeGraphiteBlackPlugin` and provides the Graphite Black theme through the Cisum plugin system.

├── Package.swift
├── Sources/ThemeGraphiteBlackPlugin/
