# VideoPlugin

Video management plugin for Cisum, providing video library browsing with grid and tile views.

## Overview

This plugin registers with ID `VideoPlugin` and provides video library functionality through the Cisum plugin system.

## Architecture

```
VideoPlugin/
├── Package.swift
├── Sources/VideoPlugin/
│   ├── VideoDB.swift
│   ├── VideoGrid.swift
│   └── VideoTile.swift
└── Tests/
```

## Features

- **Video Library**: Browse and manage video content
- **Grid View**: Grid layout for video thumbnails
- **Tile View**: Individual video tile components
