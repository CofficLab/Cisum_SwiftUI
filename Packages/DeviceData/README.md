# DeviceData

Device information and hardware data access package for Cisum.

## Overview

Provides utilities to query device capabilities, system information, and hardware specifications.

## Architecture

```
DeviceData/
├── Package.swift
├── Sources/
│   └── DeviceData.swift
└── Tests/
    └── DeviceDataTests.swift
```

## Dependencies

- `MagicKit`

## Features

- **Device Info**: Query device model, OS version, and hardware specs
- **System Capabilities**: Check available device capabilities and features
