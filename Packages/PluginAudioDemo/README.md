# AudioDemoPlugin

Audio demo and sample plugin for Cisum, providing demo audio content for testing and preview.

## Overview

This plugin registers with ID `AudioDemoPlugin` and provides demo audio content through the Cisum plugin system.

## Architecture

```
AudioDemoPlugin/
├── Package.swift
├── Sources/AudioDemoPlugin/
│   ├── AudioDemoPlugin.swift
│   ├── AudioDemoPluginInfo.swift
│   ├── AudioItemDemo.swift
│   └── AudioListDemo.swift
└── Tests/
```
