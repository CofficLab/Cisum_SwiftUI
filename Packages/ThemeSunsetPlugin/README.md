# ThemeSunsetPlugin

Sunset theme plugin for Cisum, providing a warm sunset-inspired color scheme.

## Overview

This plugin registers with ID `ThemeSunsetPlugin` and provides the Sunset theme through the Cisum plugin system.

## Architecture

```
ThemeSunsetPlugin/
├── Package.swift
├── Sources/ThemeSunsetPlugin/
│   ├── ThemeSunsetPlugin.swift
│   └── SunsetTheme.swift
└── Tests/
```
