# PluginBookControlButtons

Book playback control plugin for Cisum, providing play, pause, skip, and speed controls for audiobooks.

## Overview

This plugin registers with ID `BookControlButtonsPlugin` and provides audiobook playback control functionality through the Cisum plugin system.

## Architecture

```
PluginBookControlButtons/
├── Package.swift
├── Sources/
│   ├── BookControlButtonsPlugin.swift

│   └── BookControlRootView.swift
```
