# LikeButtonPlugin

Like button plugin for Cisum, providing a reusable like/favorite toggle button component.

## Overview

This plugin registers with ID `LikeButtonPlugin` and provides like button functionality through the Cisum plugin system.

## Architecture

```
LikeButtonPlugin/
├── Package.swift
├── Sources/LikeButtonPlugin/
│   ├── LikeButtonPlugin.swift
│   ├── LikeButtonPluginInfo.swift
│   └── LikeToggleButtonView.swift
└── Tests/
```
