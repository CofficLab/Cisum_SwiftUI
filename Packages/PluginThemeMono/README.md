# ThemeMonoPlugin

Mono theme plugin for Cisum, providing a monochromatic black-and-white color scheme.

## Overview

This plugin registers with ID `ThemeMonoPlugin` and provides the Mono theme through the Cisum plugin system.

## Architecture

```
ThemeMonoPlugin/
├── Package.swift
├── Sources/ThemeMonoPlugin/
│   ├── ThemeMonoPlugin.swift
│   └── MonoTheme.swift
└── Tests/
```
